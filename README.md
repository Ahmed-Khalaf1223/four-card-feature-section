# 📦 Four Card Feature Section

## 🌟 Project Overview  
**Four Card Feature Section** is a sleek and responsive web page that elegantly presents four key features using a card-based layout. The design is structured to ensure clarity, readability, and an aesthetically pleasing user experience.  

## 🚀 Technologies & Languages Used  
- **HTML** → Defines the page structure and content elements.  
- **CSS** → Styles the page to ensure a modern look and smooth user experience.  
  - **Normalize.css** → Standardizes browser default styles.  
  - **Google Fonts** → Uses *Poppins* and *Open Sans* for a professional appearance.  
  - **Font Awesome** → Adds scalable vector icons to enhance design.  
  - **Flexbox & CSS Grid** → Ensures a responsive and flexible layout across devices.  

## 📂 Project Structure & Features  

### **1️⃣ Main Heading & Introduction**  
- The page starts with a **double-line title** to emphasize the concept:  
  - 🏆 **"Reliable, efficient delivery"**  
  - ⚡ **"Powered by Technology"**  
- A brief paragraph explaining how AI enhances project management efficiency.  

### **2️⃣ Four Feature Cards**  
Each card highlights a unique feature, with **distinct colors and icons**:  
- 🟢 **Supervisor** → Monitors project activities to identify potential obstacles.  
- 🔴 **Team Builder** → Helps assemble the right teams for each project.  
- 🟡 **Karma** → Regularly evaluates talent to ensure high quality.  
- 🔵 **Calculator** → Analyzes past projects to improve delivery estimates.  

### **3️⃣ Layout & Design**  
The cards are distributed in **three sections** for balanced alignment:  
- **Left side** → A single card (*Supervisor*).  
- **Center** → Two stacked cards (*Team Builder* & *Karma*).  
- **Right side** → A single card (*Calculator*).  

Each **feature card** includes:  
✅ A descriptive title.  
✅ A brief explanation.  
✅ A relevant icon for better visual representation.  
✅ A distinct background color for improved readability.
